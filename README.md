# Power Platform / Dynamics 365 Case Studies

Write-ups of Power Platform and Dynamics 365 projects I've worked on. Since these are client/employer-owned systems, code and data can't be shared directly — these are descriptions of scope, my contribution, and the tech used.

## Case studies

1. [Employee Lifecycle Management System](case-studies/01-employee-lifecycle-management.md) — Dynamics 365 CRM, Model-Driven Apps, Power Automate, Dataverse. Recruitment/transfers/promotions/job-creation workflows for a state health department.
2. [City of Sierra Madre — Public Information Application](case-studies/02-city-of-sierra-madre.md) — Power Pages, Power Automate, Dataverse. Public resident portal, demo → delivered project.
3. [New Mexico Environment Department — Enterprise Application](case-studies/03-new-mexico-environment-department.md) — Model-Driven Apps, PCF, Power Pages, Power Automate, Dataverse, JavaScript. Full-stack build across the entire Power Platform.
4. [HR Accelerator](case-studies/04-hr-accelerator.md) — Power Automate, Business Process Flows, Dataverse, JavaScript. Reusable HR process automation solution.
5. [Oklahoma OHSB — Case Management System](case-studies/05-ohsb-oklahoma.md) — Model-Driven Apps, Dashboards, Power Automate, Dataverse, JavaScript. Case tracking with reporting dashboards, demo → delivered project.
