# Oklahoma OHSB — Case Management System

**Client:** OHSB, State of Oklahoma
**Role:** Power Platform Developer
**Type:** Proof-of-concept demo → converted into a delivered project
**Stack:** Dynamics 365 Model-Driven Apps, Power Automate, Dataverse, JavaScript

## Overview

A case management system built for OHSB (State of Oklahoma), used to track and manage cases with reporting/analytics dashboards for case status and workload visibility. Started as a proof-of-concept demo and was converted into a delivered project after client approval.

## My contribution

- **Model-Driven App** — entity/table design, forms, and views for case records
- **Dashboards** — built reporting dashboards for case tracking and status visibility
- **Power Automate** — flows for case status updates and notifications
- **JavaScript customizations** — form-level scripting and client-side logic
