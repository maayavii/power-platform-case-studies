# New Mexico Environment Department — Enterprise Application

**Client:** New Mexico Environment Department
**Role:** Power Platform Developer (full-stack)
**Type:** Proof-of-concept demo → converted into a delivered project
**Stack:** Dynamics 365 Model-Driven Apps, PCF, Power Pages, Power Automate, Dataverse, JavaScript

## Overview

An enterprise application built for the New Mexico Environment Department, covering both an internal model-driven application and a public-facing Power Pages portal. Started as a proof-of-concept demo and was converted into a delivered project after client approval — this was the most complete end-to-end build across the Power Platform stack among my projects.

## My contribution

Worked across nearly every layer of the platform:

- **Model-Driven App** — entity/table design, forms, views, business rules
- **PCF (PowerApps Component Framework)** — built custom controls for functionality not achievable with out-of-the-box components
- **Power Pages** — public-facing portal pages and forms
- **Power Automate** — flows for approvals, notifications, and data processing
- **JavaScript customizations** — form scripting and client-side logic on model-driven app forms
